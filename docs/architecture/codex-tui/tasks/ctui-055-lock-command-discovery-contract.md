# CTUI-055 — Lock Command Discovery Contract

- Status: Accepted 2026-09-04; unpublished draft
- Source: [Codex TUI baseline](../../codex-tui-baseline.md)
- Depends on: CTUI-030

## Outcome

Decide a literal command-discovery fixture and action mapping before
implementation.

## Scope

- Record source-cited normal and narrow fixtures with exact geometry, entry,
  labels, emphasis, selection, navigation, and dismissal behavior.
- Map visible choices to existing Revolvr commands, eligibility, and guards.
- Distinguish observed Codex evidence from Revolvr policy.

## Acceptance

- Fixtures and matrices settle every visible state, entry path, selection,
  command mapping, and draft-preserving dismissal.
- CTUI-060 can implement the contract without selecting fixtures or policy.

## Verification

- Compare fixtures against fresh fixed-geometry side-by-side evidence.
- Review every listed action against current Revolvr command authority.

## Not Included

- Product code, dependency changes, or canonical publication.
- Command semantic changes, focused surfaces, launch redesign, or broad restyle.
